Computer Networks (CN) Concept
IPv4 Address

Example:

192.168.10.128


An IPv4 address has 4 parts, called octets

Each octet range: 0 – 255

0 → Network/Base address

255 → Broadcast address

So each number in 192.168.10.128 is an octet.

Docker Basics
🔹 Docker Terminologies

Image → Blueprint of an application

Container → Running instance of an image (running app)

Docker Daemon → Background service that manages Docker

Docker Workflow → Steps to build and run containers

Dockerfile → File that contains instructions to build an image

Docker Hub → Repository for images (Public / Private, like GitHub)

📄 Dockerfile Format (Basic)

FROM image
WORKDIR /app
COPY . .
CMD ["command"]

Explanation:

FROM → Base image

WORKDIR → Working directory inside container

COPY → Copy files into container

CMD → Command to run the application

🔁 Docker Workflow

Write application code

Create Dockerfile

Build Docker image

Push image to Docker Hub

Pull image into server

Run the container

📝 Summary

Docker → Tool

Image → Blueprint

Container → Running app

Dockerfile → Instructions to build image

Docker Hub → Image repository
